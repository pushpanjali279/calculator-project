# 🧮 Calculator Web Application

A simple and interactive calculator developed using HTML, CSS, and JavaScript. It features a modern dark-themed interface with circular buttons and supports basic arithmetic calculations.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)
- Decimal number support
- **AC:** Clear all input
- **DEL:** Delete the last entered character
- **00:** Enter double zero quickly
- **=:** Calculate and display the result
- Modern dark-themed interface
- Interactive calculator buttons

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and user interface design
- **JavaScript** – Calculator operations and interactive functionality

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The calculator will open in your web browser.
5. Use the calculator buttons to perform calculations.
