# 🧮 Calculator Web Application

A simple, interactive, and user-friendly calculator built using HTML, CSS, and JavaScript. The project features a modern dark-themed interface with circular buttons and supports basic mathematical calculations.

## 📌 Project Overview

The Calculator Web Application is a frontend development project designed to perform basic arithmetic operations through an interactive graphical user interface. It demonstrates the use of HTML for structure, CSS for styling, and JavaScript for functionality.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Percentage button
- 🔢 Decimal number support
- **AC (All Clear):** Clears the current calculation
- **DEL (Delete):** Deletes the last entered character
- **00 Button:** Allows quick entry of double zeros
- **Equals (=):** Displays the calculation result
- 🎨 Modern dark-themed user interface
- 🟢 Green-colored operator buttons
- 🟠 Orange-colored equals button
- 💻 Simple and easy-to-use layout

## 🛠️ Technologies Used

- **HTML5** – Creates the calculator structure.
- **CSS3** – Provides styling, layout, colors, and visual effects.
- **JavaScript** – Handles button interactions and mathematical calculations.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Double-click `index.html` to open it in your web browser.
5. Use the calculator buttons to perform calculations.

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/calculator-project.git
```

Replace `YOUR-USERNAME` with your GitHub username.
